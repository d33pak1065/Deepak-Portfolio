## Development Approach

My development workflow follows six practical stages:

1. **Understand** — Clarify requirements, user flows, business needs, and edge cases.
2. **Build** — Develop maintainable features using appropriate architecture, reusable UI, and state management.
3. **Integrate** — Connect applications to REST APIs, Firebase, maps, payments, and other required services.
4. **Test** — Validate user flows and integrations, identify issues, and fix bugs.
5. **Ship** — Prepare production builds and deploy applications to their target platforms.
6. **Improve** — Maintain applications through bug fixes, performance improvements, and new features.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/d33pak1065/Deepak-Portfolio.git
cd Deepak-Portfolio
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
