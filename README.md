## Development Approach

My development workflow is built around six practical stages:

1. **Understand** — Clarify requirements, user flows, business needs, and edge cases before implementation.
2. **Build** — Turn requirements into maintainable features using appropriate architecture, reusable UI, and state management.
3. **Integrate** — Connect applications with REST APIs, Firebase, maps, payments, databases, and other required services.
4. **Test** — Test complete user flows, integrations, and edge cases while diagnosing and fixing issues.
5. **Ship** — Prepare production builds, complete release requirements, and deploy applications to their target platforms.
6. **Improve** — Use production feedback, crash reports, bugs, and new requirements to continuously improve the application.
